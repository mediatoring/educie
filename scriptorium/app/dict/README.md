# Spell-check dictionaries (Hunspell format)

- `cs_CZ.*` – Czech dictionary from LibreOffice (https://github.com/LibreOffice/dictionaries/tree/master/cs_CZ), GNU GPL.
- `de_DE_frami.*` – German dictionary "frami" from LibreOffice (https://github.com/LibreOffice/dictionaries/tree/master/de), GNU GPL / LGPL.

The user's own words (names, places, period spelling) are stored outside the repository in `<data>/_dict/user.txt`.
